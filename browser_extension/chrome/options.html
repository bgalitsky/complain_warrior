Live complaint database

Sign in to CW and select a complaint. Each click fetches that record again. No JSON import or field-review screen is needed.

Chrome asks for access to this CW host only. Your login cookie is sent to CW, never to the third-party form.

Optional JSON fallback

Import once per browser session. Every click then reuses this data automatically. A file edited on disk is not reread; import it again to refresh.

Use

Open the intended third-party form, then click the CW toolbar icon. It fills known blank fields immediately. Review and edit the form itself. Click CW again on the next page; existing values stay unchanged.

No automatic signatures, CAPTCHA, uploads, declarations, or submission. The website may autosave entered values.
